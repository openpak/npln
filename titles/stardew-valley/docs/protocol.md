# Protocol Research

No Stardew Valley Nintendo Switch application protocol is currently identified.

## Confidence policy

- **CONFIRMED:** reproduced by a documented observation or test.
- **HIGH:** multiple observations strongly support the interpretation.
- **MEDIUM:** plausible interpretation with incomplete evidence.
- **LOW:** weak inference that requires a targeted experiment.
- **SPECULATIVE:** an untested possibility.

Hostnames, ports, endpoint names, message names, and field meanings must not be added as facts without a sanitized reproduction procedure. Unknown binary fields retain neutral names such as `field_04`.

The current observer produces transport metadata only. Its synthetic tests prove observer behavior, not retail-client behavior.
